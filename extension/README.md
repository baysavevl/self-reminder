# Self Reminder browser extension

Bản extension Manifest V3 dùng để mở nhanh Self Reminder từ toolbar. Extension không lưu reminder riêng; dữ liệu vẫn nằm ở database của webapp.

## Cài trên Chrome/Edge/Brave

1. Mở `chrome://extensions` (hoặc trang extensions tương ứng).
2. Bật **Developer mode**.
3. Chọn **Load unpacked**.
4. Chọn thư mục `extension/` trong repository.
5. Ghim **Self Reminder** lên toolbar.

Đây là bản launcher đầu tiên. Các nút mở webapp dùng chung dữ liệu và session của webapp trong tab trình duyệt.
